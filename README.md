##  Sobre mim

Sou Engenheiro de Computação e desenvolvedor de software com experiência em ambientes corporativos, atuando no desenvolvimento de soluções para automação de processos, análise de dados, integração de sistemas e digitalização de processos de negócio.

Atualmente atuo em Gestão Corporativa, trabalhando com sistemas, dados e processos relacionados à gestão de metas e indicadores. Desenvolvo soluções utilizando Power BI, Power Automate e Power Apps, além de atuar com SAP SuccessFactors, APIs e integração entre sistemas.

Também desenvolvo projetos independentes com foco em desenvolvimento web e backend, utilizando JavaScript, React, Python, PHP, Node.js, SQL e Docker.

Meu objetivo é transformar problemas de negócio em soluções de software eficientes, automatizadas e orientadas a dados.

##  Projetos em destaque

### 🌱 IoT de Cultivo

Sistema automatizado para cultivo agrícola em estufa controlada, desenvolvido como TCC da Engenharia de Computação.

O projeto utiliza sensores, atuadores e microcontrolador para monitorar e controlar condições ambientais de acordo com os parâmetros necessários para a cultura.

**Foco:** IoT · Sistemas Embarcados · Automação · Sensores · Atuadores

---

### 📊 Dashboard de Metas Corporativas

Solução analítica desenvolvida em Power BI para acompanhamento de metas corporativas, resultados individuais e colaborativos.

O projeto contempla diferentes níveis de visualização conforme a estrutura hierárquica, acompanhamento de pontuação, análise individual de metas e controle de acesso às informações.

**Foco:** Power BI · DAX · Modelagem de Dados · Data Visualization · RLS

---

### ⚙️ Automação do Processo de Gestão de Metas

Automação desenvolvida em Power Automate para acompanhamento das etapas dos painéis de metas e comunicação automática entre empregados, gestores e focais de gestão.

A solução substituiu uma cadeia de notificações manuais e passou a processar milhares de comunicações em poucos minutos. O mesmo conceito também foi reutilizado pela área de TI durante os testes de implantação do SAP S/4HANA.

**Foco:** Power Automate · Process Automation · Workflow · Systems Integration

---

### 🏢 MetaHub — Digitalização da Gestão de Metas

Aplicação em desenvolvimento utilizando Power Apps para digitalizar e automatizar o processo corporativo de gestão de metas.

A solução busca substituir 21 etapas manuais e aproximadamente 20 planilhas por um fluxo digital centralizado, com integração ao SAP SuccessFactors e mecanismos de rastreabilidade e auditoria.

**Foco:** Power Apps · Power Automate · Process Digitalization · Systems Integration

---

### 🛒 E-commerce

Projeto de estudo prático de desenvolvimento web envolvendo front-end, back-end, banco de dados, Docker e deploy.

**Foco:** JavaScript · PHP · MySQL · Docker · Web Development
